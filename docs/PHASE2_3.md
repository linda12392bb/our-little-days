# Phase 2/3 最小試用版（0.2.0）

沿用 Phase 1 的 Python / PySide6 桌面、指定 HWND / PID 的 PrintWindow backend、十三份人格與 SQLite；沒有重新建立專案或雲端網站。

## 順序與模型

1. 已先接本機安全設定、集中費用紀錄與預算攔截。
2. Phase 2：本機畫面變化門檻、穩定畫面、單次圖片理解、事件識別及去重。
3. Phase 3：單次請求產生 0–4 位住戶的自然互動；接話對象與回覆 ID 保存。
4. 先在自己的 Windows 執行兩項單次真實成本測試，再手動啟用長時間陪伴。
5. 下一輪依真實回應調整語氣、關西腔與事件偵測。WGC 遊戲相容性、自動長期記憶候選萃取、付費摘要不在這次最小版本範圍。

預設模型 **gpt-4.1-mini**，支援圖片理解。它不是 GPT-6 LUNA。介面也提供 gpt-4o-mini / gpt-4.1，選擇後必須核對新價格並重做成本測試。完整 source_text、人格、思考、語言、外貌、關係與禁則全部放入每次請求；不靠削減正式人格省錢。所有長期記憶及重要事件按目前世界線載入，近期聊天最多 60 則。若完整上下文超過安全容量，拒絕呼叫而非截斷人格。原始文件全域規則另原文保存在 data/global_character_rules.txt。

## 費用與安全

- 月預算預設 NT$500，可修改。畫面分析、多人對話、成本測試共用 **同一個** UsageLedger。未實作付費摘要，也沒有自動重試；未來新增這些請求仍必須走相同 reserve()。
- 每次發送前，用完整文字的保守 token 上界、圖片保守上界與最大輸出量預留費用。月內已有估算／預留金額加上新預留額超過預算，即拒絕呼叫。單一請求處理中不再並行。
- 完整回應以 provider 的 prompt_tokens / completion_tokens 結算。包含模型回報的輸出用量；快取輸入仍按完整輸入價保守估算。價格與匯率按每次請求快照保存。
- 回應錯誤但有 usage：先記錄費用，再拒絕不合格角色輸出。連線逾時、取消、異常退出而沒有用量：保留預留額、停用 AI，不自動重試。取消本機 HTTP 程序不代表平台能撤銷已收到的請求。
- 顯示今日／本月請求、輸入輸出 token、本機估算、待確認金額及本月剩餘預算。**剩餘＝預算－已結算估算－待確認／進行中預留**（最低顯示 0）。月與日以台灣 UTC+8 切換。
- 費用是本機估算，**不是 OpenAI 實際帳單或信用餘額**。參考價格 gpt-4.1-mini $0.40 / $1.60、gpt-4o-mini $0.15 / $0.60、gpt-4.1 $2 / $8（USD／百萬 token），匯率預填 33。官方最新頁在開發環境回覆 403，未完成即時查價；必須在設定勾選核對。實際帳單、稅金、匯差、他處用量以平台為準。
- 預算依當前設定價格估算，不是供應商端硬上限；錯誤價格可能低估。使用者可同步設定 OpenAI 平台預算通知，但平台通知不應被當成一定會硬停的保證。
- Key 僅在 Windows 本機密碼欄輸入，以 DPAPI 加密至目前 Windows 帳號。不在 JSON、SQLite、日誌或 GitHub 保存明文。非 Windows 不提供明文替代。憑證錯誤不會降低 TLS 驗證。
- 唯一 API 目的地 https://api.openai.com/v1/chat/completions，拒絕 HTTP redirect，不使用付費自動重試。不採集桌面或其他視窗。畫面只縮為最大 960px JPEG、存在記憶體，單次分析才上傳。
- 保存設定不呼叫 API；金鑰存在也不等於啟用 AI。沒有傳送同意、金鑰或預算時，不發送請求。每次啟動 AI 預設關閉，兩項用量測試都通過才可啟用。模型、價格、匯率、輸出上限或金鑰版本變更需重新測試。

## 六秒擷取與安靜

本機擷取預設 6 秒，AI 最短間隔預設 120 秒（可改 60–3600）。**間隔不是排程觸發**：畫面不變，經過多久都不新呼叫。以 32×24 網格比較 RGB，至少 12% 格點明顯改變且平均差異達門檻，再要求連續兩次相對穩定。時鐘、游標及小動畫一般會被濾掉。

第一次自主觀察可分析一次。請求發出後才更新比較基準。大範圍動畫可能被當成改變；門檻過高也可能漏掉小範圍文字事件。這是可調整的啟發式門檻，不保證所有影片／遊戲情境完美。AI 再根據近期事件判斷 meaningful，可保持安靜；同一世界線已保存的 event_key 不重複產生發言。事件文字識別不是語義相似度的絕對保證，品質待實機改善。

不在安靜時付費生成角色續聊；一個新事件或使用者訊息用一次請求產生自然的短多人對話。recipient_ids / reply_to_index 保存為 SQLite recipient_ids_json / reply_to。訊息標題顯示接話對象，原生語言與繁中翻譯按段落緊接。原始 source_text 不被模型更改，AU 以目前世界線限定。

## 持久資料與還原

- apartment.sqlite3：原有七表不變。AI 訊息與接話、畫面重要事件持久保存；多位訊息及同一事件在同一交易提交。
- 畫面觀察標示 `user_confirmed:false`，不直接升格為使用者已確認的長期記憶，不擅自改變戀愛關係。手動長期記憶仍可由「記憶、事件與備份」保存。
- api-usage.sqlite3：用量與費用設定分開存，還原聊天不倒退已花費金額。設定中可備份／合併還原用量；請求 ID 去重，保留現有新用量，不提供清零捷徑。
- openai-key.dpapi：加密憑證不放入聊天／用量備份。移到不同 Windows 帳號或重裝 Windows 後需重新輸入 Key。
- 更新程式沿用 %LOCALAPPDATA%\OurLittleDays。角色種子不覆寫使用者既有人格。唯一已授權補充：序在既有 tone / behavior 後加入調戲／♡，先備份原 SQLite，其他欄位、原文與十二位角色保留。
- 暫停 AI 不刪記憶，也可繼續本機擷取。暫停觀察／停止／關閉會取消 AI 與擷取；異常退出的 API 預留額在下次啟動標示 interrupted，不自動退款或恢復付費分析。

## 驗證界線

使用者已回報 Phase 1 在 Windows 11 成功開啟、十三名單／氣泡顯示、Chrome 指定擷取預覽與 6 秒擷取。不能延伸為 Phase 2/3 已通過 Windows 實機。

開發測試全部使用模擬 API，不發送付費請求。Windows EXE 仍使用 Windows Python + PyInstaller 於 Linux / Wine 建置，驗證官方 DLL 來源、完整人格、離線 UI、SQLite、DPAPI 測試金鑰加密往返及封裝後子程序。這些不能代替 Windows 11 的新版本驗收。

真正 API 成本、帳號模型可用性、語氣品質、自主發言與正式 Windows DPAPI 帳號隔離都需在使用者 Windows 執行；沒有收到真實 API usage 前不會標示成本測試通過。
