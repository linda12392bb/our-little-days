# Phase 1 驗收

本文件是待執行的 Windows 驗收清單，不代表已在 Windows 測過。雲端 Linux 的實際結果另見 `artifacts/smoke-report.json`（執行 `scripts/smoke_ui.py` 後產生）。

## 自動驗證

在 Windows 10／11、有互動式桌面的工作階段，安裝依賴後執行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

`test_windows_native.py` 建立一個不同程序的真實 Qt 視窗，驗證列舉、實際擷取中央像素，以及關閉後報錯。Linux 必須跳過此測試，不能把跳過算成通過。

## 進入下一階段條件

先確認至少一個普通 Windows 視窗的擷取與原生桌面操作正常，再處理目標遊戲的 backend 相容性。Phase 2 才實作事件理解；Phase 3 的核心驗收是使用者不輸入時，依真實新事件自主發言。Phase 1 的展示畫面與測試訊息不能滿足這項核心驗收。
