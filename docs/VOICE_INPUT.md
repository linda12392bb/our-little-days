# 自動語音輸入 · 自主陪伴試用版 0.4.4

0.3.2 修正從 RAM／stdin 送入 Whisper 時沒有文字輸出的問題；保留音訊不落地，新增模型驗證／辨識狀態、等待秒數、語音長度及待處理段數。辨識忙碌時最多暫存三段，超過的片段會明確顯示略過，不取消正在辨識的語音。CPU 最多用四個執行緒；small 單段最多等待 180 秒，其他模型 90 秒。

0.3.1 修正 Qt 6.10 的音訊狀態列舉比對：原本正常啟動可能被誤判為錯誤並立刻停止，導致「麥克風啟動失敗」。也修正同步啟動失敗後仍存取已停止音源，並顯示 OpenError／IOError／例外類型供診斷。已下載模型、人格、聊天、記憶及 API 設定沿用。

沿用原 Windows 桌面公寓與 SQLite。手動開啟麥克風後，自動偵測妳說話，不需要每句按鍵，也不需要喊住戶名字。角色朗讀尚未加入。

## 第一次使用

1. 舊版「記憶、事件與備份」先備份，關閉舊程式。從私人 GitHub 下載語音 ZIP，全部解壓到新資料夾，雙擊 OurLittleDays.exe。保留同層 `_internal` 和 `speech-runtime`；不用安裝 Python。
2. 戴上耳機。在 Windows「設定 → 隱私權與安全性 → 麥克風」允許桌面應用程式使用麥克風。「設定 → 系統 → 音效 → 輸入」先確認妳自己的麥克風有音量。
3. 公寓右側往下捲到「語音輸入 · 本機離線」。選真正的 USB／耳機麥克風，保持 **base 多語**、**自動 · 繁中／日文／混合**。
4. 按「下載所選離線模型（一次）」。一次下載約 **142 MiB**，需網路，下載內容只是免費模型權重，沒有 API 費用；不會上傳收音。成功會顯示模型已驗證。之後辨識不需網路。
5. 按「開啟麥克風 · 自動偵測」。先維持 AI 關閉，輕聲說「蛤？」「欸？」「不是吧」，觀察音量與文字預覽。再說「何これ？不是吧？」測混合語句。只測辨識不花 API 費用。
6. 要住戶自動接話，先按原本 API 設定完成兩項單次費用測試，再勾「啟用文字 AI 回覆」。保持語音「預覽後自動交給住戶（需文字 AI）」勾選。停語約 **1.5 秒**完成一段辨識，預覽後 **2.5 秒**自動交給住戶；可以編輯或取消，不需要每次按送出。

模型下載失敗時，可以在瀏覽器開官方 [base 多語模型下載](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin)，下載後在公寓按「匯入已下載的官方模型…」，選 ggml-base.bin。會核對官方 v1.8.2 雜湊，錯誤檔不載入。不要下載 base.en（只有英文）。

在公寓內按「下載所選離線模型」成功後，模型就已安裝，**不用再匯入**；選 small 並顯示「已下載」時，直接開啟麥克風即可。只有透過瀏覽器另外下載 ggml-small.bin／ggml-base.bin／ggml-tiny.bin，才需要在公寓選相同模型並匯入該檔案。

## 從 0.3.1 更新並測試空白預覽修正

關閉舊程式，把 0.3.2 ZIP 全部解壓到新資料夾，開啟新 OurLittleDays.exe，確認右側版本為 0.3.2。原本的 small 模型、聊天、角色、關係與設定沿用，不需重新下載或匯入。選 YETI X 與 small，保持 AI 關閉，說一句話後安靜超過設定的 2.5 秒停語等待，再觀察模型驗證／辨識狀態及已等待秒數，完成後應顯示文字預覽。2.5 秒是停語判定時間，並不保證辨識也在 2.5 秒內完成；small 使用 CPU 時較慢，可視需要改用 base／tiny。

## 小聲與短句調整

- 預設門檻 **−48 dBFS**、增益 **+6 dB**。太小聲偵測不到，可先關麥克風，改門檻 **−55**、增益 **+12**，再開啟測試。數字越負越靈敏，但也更容易收背景聲；靠近麥克風比極度提高增益可靠。
- 停語等待可調 **0.5–3 秒**，預設 1.5 秒。句子常被切斷可增加到 2 秒。
- 本機 VAD 接受短語音片段，不要求完整句子。這不保證模型一定聽懂每次「蛤？」；短、小聲、中日混合辨識品質需要實機驗收。
- tiny 多語較快；small 多語約 466 MiB，通常有助準確度但更慢、占更多記憶體。請先測 base，再依電腦速度選擇。
- 本版每段最多約 15 秒；辨識忙碌會暫存至多三段 RAM 音訊，超過時略過後續片段並顯示數量，保留正在辨識的語音。

Whisper 多語支援中文與日文。中文辨識文字轉台灣繁體；含日文假名的段落保留日文，避免改壞漢字。**同一段混合句可能留下簡體中文字，可在預覽修正**；語言自動判斷與翻譯保真後續再改善。

## 畫面、住戶與費用

語音送出時，把辨識文字與目前指定視窗的最近一張預覽送給原住戶引擎；沒有畫面時只送文字。十三份完整人格仍全部提供，由同一次請求決定少數住戶回應及彼此接話。住戶語言與繁中翻譯規則沿用，沒有改角色資料。

Whisper 是本機語音辨識模型；住戶對話維持 **gpt-4.1-mini**，不是 GPT-6 LUNA。語音回覆請求共用 NT$500 月預算、每日／每月用量與剩餘預算。畫面一起送出也計入同一次預留與結算。估算仍與平台帳單分開。

AI 未啟用時只顯示語音預覽，不暗中付費。預算不足時停止 AI，麥克風可以繼續本機辨識。按「暫停所有 AI」停止新的付費回覆，麥克風預覽可繼續。關閉麥克風不停止畫面自主聊天；安靜時畫面事件仍依原設定獨立工作。

## 隱私、保存與關閉

- 每次開啟程式，麥克風與 AI 都關閉，必須妳自己啟用。裝置移除會停止收音，不自動改收其他麥克風。
- 原始音訊只在有上限的記憶體與本機辨識子程式 stdin 中流動；沒有錄音檔、沒有背景音訊上傳。關閉麥克風會丟棄尚未辨識的音訊、取消本機辨識及尚未送出的自動文字；已送出的 AI 工作可另按暫停。
- **「永久保存辨識文字到聊天」預設不勾**。未勾時，只在畫面預覽與當次 AI 請求使用文字；住戶回覆照原規則保存，可能包含對妳的話的引用。勾選後，送出的文字才寫入現有 apartment.sqlite3，並納入公寓備份。
- 語音靈敏度、模型、語言及保存選項會記住；收音開啟狀態不恢復。模型位於 `%LOCALAPPDATA%\OurLittleDays\speech-models`，可重新下載；角色、關係、記憶仍在原 SQLite，沒有重置。
- 關閉程式停止麥克風、辨識、擷取與本機 API 工作，已保存資料保留。取消已送到平台的請求不能保證免計費。

只選 Windows 音訊輸入，並排除已知 Stereo Mix、系統迴路與虛擬混音裝置。**喇叭播放的動畫若被實體麥克風收進來，本版不能可靠分辨是不是妳**；VAD 不是聲紋辨識或回音消除。請戴耳機，勿用外放作為正式測試。

## Windows 實測清單（目前待驗收）

1. 未開麥克風時等五分鐘：無收音，沒有語音 API 請求。重開也維持關閉。
2. AI 關閉，開麥克風後安靜十分鐘：音量顯示可有底噪，但無文字、無新增 API 請求；如有誤判記下環境與門檻。
3. 分別輕聲說短句、繁中、日文與混合句：記錄預覽是否正確、延遲、是否截斷，調整靈敏度與停語時間重測。
4. 戴耳機播放遊戲／動畫但自己不說話：不應產生辨識文字；接著自己說話應可辨識。外放聲音無可靠排除保證。
5. 啟用文字 AI、自動送出，說一句話：產生一次住戶回覆請求，能參考指定視窗；確認少數住戶接話、語言及翻譯。核對用量與剩餘預算。
6. 在預覽等待期間取消：不新增請求；關閉麥克風：晚到辨識不得送出。AI 暫停：只預覽，不付費。
7. 不保存辨識文字時重開：用戶語音不在歷史，住戶回覆在。勾選保存後測試：用戶文字與回覆重開仍在，公寓備份／還原保留。
8. 麥克風關閉但畫面自主 AI 啟用：新畫面仍能聊天；安靜且畫面靜態則不持續新增 API。
9. 收音／辨識時正常關閉或工作管理員結束，重開：麥克風關閉，已保存角色與聊天仍在。拔除麥克風不改收系統聲音。

開發端已測本機 VAD、短片段、分句、音訊格式轉換、取消、文字保存與共用 AI 預算接線；**Hugging Face 在雲端受網路限制；另從公開 GitHub 取得 tiny 權重並核對官方雜湊，已用官方公開英文範例實際驗證修正前空白、修正後回傳文字。仍沒有 Windows 麥克風、小聲短句及中日混合品質驗收**。公開英文範例與封裝／模擬成功不能代表妳的麥克風、小聲辨識、回音隔離或模型聊天品質通過。

後續先依上述實測改善短句、混合語句、誤觸發與辨識速度，再考慮聲紋／回音消除及角色語音朗讀。
