# Windows 安裝與啟動說明

這是「月色不打烊」Phase 1 的 Windows 本機桌面試用版。支援 Windows 10／11、64 位元的 Intel／AMD 電腦；目前未提供 ARM 專用版本。

已製作 Windows `.exe` 與完整可攜式 ZIP。它包含 Python 與介面需要的檔案，使用者不必另外安裝 Python、下載原始碼或輸入指令，也不需要 API Key 或雲端發佈。

**目前尚未完成真正 Windows 電腦的人工操作與指定視窗擷取驗收。** 此版以 Windows Python 與 Windows PyInstaller 在 Linux＋Wine 相容環境建置；通過的封裝檢查使用離線介面及臨時資料，不能視為 Windows 實機測試通過。

## 下載、解壓縮與開啟

1. 下載 `OurLittleDays-Windows-x64-Phase1-preview.zip`。
2. 在 Windows 的「檔案總管」找到下載的 ZIP；按右鍵，選「全部解壓縮」。Windows 11 若未顯示此項，可先選「顯示其他選項」。
3. 選擇你自己的文件資料夾，例如 `文件\OurLittleDays-Phase1`，再按「解壓縮」。請等它完成。
4. 打開解壓縮後的 `OurLittleDays` 資料夾，找到 `OurLittleDays.exe`。若 Windows 隱藏副檔名，檔名可能只顯示 `OurLittleDays`，類型是「應用程式」。
5. 雙擊 `OurLittleDays.exe`，等介面出現。第一次啟動可能稍慢。不要直接從 ZIP 裡開啟。
6. 之後每次都雙擊同一個 `OurLittleDays.exe` 即可。可在檔案上按右鍵，選「傳送到 → 桌面（建立捷徑）」，方便下次開啟。

**必須保留整個 `OurLittleDays` 資料夾，包括 `_internal`。** 不能只把 `.exe` 單獨搬到桌面；請建立捷徑，或搬動整個資料夾。

這是解壓縮即可使用的版本，沒有安裝精靈，不需要系統管理員權限。開始擷取與聊天都在本機執行。這個版本沒有模型服務連線；角色訊息是明確標示的測試訊息，尚不能自主聊天或理解畫面。

## 第一次啟動時應看到什麼

- 一個可拖動、縮放、最小化的公寓視窗。
- 十三位聲道的名單；可選角色加入測試訊息。
- 右側的指定視窗選擇、預覽與開始／暫停／停止按鈕。
- 觀察尚未開始，API 顯示離線。
- 下方可輸入文字；Enter 送出，Shift＋Enter 換行。

## 用記事本測試指定視窗擷取

1. 從 Windows「開始」選單打開「記事本」，輸入 `這是我的擷取測試 001`。保持記事本開著且不要最小化。
2. 回到公寓，按右側「重新整理視窗」，在下拉選單選擇剛才的記事本。
3. 按「開始陪伴」，等一個擷取間隔，查看右側預覽。
4. 確認預覽是記事本，且能看到你輸入的文字；修改記事本文字，觀察預覽是否隨之更新。
5. 開啟另一個視窗並切到它，再回公寓查看：預覽應仍是先前選定的記事本，不應改成整個桌面或另一個視窗。
6. 要換目標時，先按「停止」，再選另一個視窗並按「開始陪伴」。

若目標最小化或關閉，程式應顯示錯誤並停止擷取；還原記事本後，重新選擇與開始。先測試普通記事本；遊戲、影片播放器、受保護內容或特殊渲染可能是黑畫面或不相容，不能保證都支援。

## 測試暫停、恢復與停止

1. 擷取記事本時，按「暫停」。預覽應清空，狀態應顯示暫停，聊天與記憶仍在。
2. 在記事本修改內容，確認暫停期間沒有新預覽。
3. 按「恢復陪伴」。應繼續同一個記事本的擷取。
4. 按「停止」。預覽應清空，擷取應結束；聊天紀錄仍在。

暫停與停止只控制畫面觀察，不代表刪除聊天或角色記憶。

## 測試關閉、重新開啟與保存

1. 在公寓輸入 `Windows 保存測試 001`，按 Enter。確認聊天室真的出現這則訊息；尚未送出的輸入草稿不包含在聊天保存中。
2. 選擇一位角色，按「加入測試訊息」。它應有測試標示。
3. 打開「記憶、事件與備份」，在「重要事件」記下 `Windows 事件測試 001` 並按「保存重要事件」。
4. 切到「長期記憶」，選一位角色，記下 `Windows 記憶測試 001` 並按「保存長期記憶」。留在同一條世界線測試。
5. 關閉記憶視窗，再按公寓右上角的 X，正式結束程式。最小化只會把視窗縮到工作列，並不等於關閉。
6. 再次雙擊 `OurLittleDays.exe`。聊天、角色設定、關係、重要事件與長期記憶應仍在；不應重複加入初次歡迎訊息。
7. 重新開啟後畫面觀察應為停止狀態，預覽應是空的。這是預期行為；要繼續觀察，重新選擇視窗並按「開始陪伴」。

關閉時會停止擷取子程序；目前沒有模型 API 請求。重開會恢復已儲存內容，不會自動恢復畫面觀察。

## 備份與還原

1. 在公寓打開「記憶、事件與備份」，按「備份整間公寓…」。
2. 選擇文件或外接磁碟資料夾，使用新的檔名，例如 `公寓備份-2026-10-10.sqlite3`，按儲存。
3. 等到程式顯示備份成功。備份包含角色、各世界線關係、聊天、事件與長期記憶。
4. 更新程式、換電腦或重裝 Windows 前，請把備份放到安全且不會一起刪掉的位置。
5. 需要恢復時，在程式裡按「還原備份…」，選擇備份。仔細閱讀確認視窗：還原會以該備份的狀態替換目前資料，只有同意後才進行。
6. 還原前，程式會自動另存目前資料的安全備份；還原後擷取會停止，聊天會重新載入。

日常資料存於 `%LOCALAPPDATA%\OurLittleDays\apartment.sqlite3`，與程式資料夾分開。可以雙擊程式資料夾內的「開啟資料資料夾.cmd」查看；資料庫不是可直接閱讀的聊天文字檔。請用程式的備份功能，避免在程式執行時只複製一個資料庫檔而漏掉尚在 WAL 的內容。

更新時先備份、關閉程式，把新版解壓縮到另一個資料夾，再開啟新版 `.exe`；使用同一 Windows 使用者會讀取原本資料。已有資料庫的角色設定不會被新版種子檔自動覆寫，也不會自動清空聊天或重置關係。

## 測試異常中斷

請先完成備份。送出 `Windows 異常中斷測試 001` 並確認訊息出現在聊天室後，按 Ctrl＋Shift＋Esc 打開工作管理員，找到 `OurLittleDays`，選「結束工作」。再開啟公寓，確認已送出的訊息與記憶仍在，且擷取沒有自動開始。這項檢查結果請填在隨附的 `WINDOWS_TEST_CHECKLIST.md`；目前未替你宣稱通過。

## 若無法啟動

- 找不到 `.exe` 或出現缺少 DLL：確認使用「全部解壓縮」，且 `_internal` 與 `.exe` 位於同一資料夾。
- 提示公寓已被使用：檢查是否已開啟另一個公寓視窗；先關閉另一個，勿刪除資料庫。
- 出現「公寓啟動失敗」：保留錯誤視窗內容。若有產生紀錄，它位於資料資料夾的 `logs`，可用記事本開啟。
- 若 Windows 顯示未識別或封鎖提示：此試用版尚未簽章；保留提示供診斷，不需要關閉防毒或調低系統安全設定。
- 擷取空白：先換普通記事本測試，保持目標未最小化。請記錄目標程式名稱及完整錯誤文字。

## 只有想自行重建才需要 Python

一般使用者直接使用上述 ZIP，不需要這些步驟。原始碼另附「製作Windows執行檔.cmd」，供自行重建用：

1. 下載並解壓縮原始碼 ZIP。
2. 從 Python 官方網站安裝 Python 3.12 的 Windows 64 位元版本，安裝時保留 Python Launcher。
3. 雙擊原始碼根目錄的「製作Windows執行檔.cmd」。它會下載鎖定的依賴、檢查角色資料、建置並檢查封裝。
4. 成功後，產物在 `artifacts\OurLittleDays-Windows-x64-Phase1-preview.zip`。將整個 ZIP 交付即可，接收者不用 Python。

這是本機建置方式；不需要把專案部署成雲端網站。建置與離線封裝檢查成功，也不等於 Windows 實機的指定視窗擷取驗收成功。
