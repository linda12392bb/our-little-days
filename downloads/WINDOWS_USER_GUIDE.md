# Windows 安裝與啟動：自動語音輸入試用版 0.3.1

這是 Windows 本機桌面程式。ZIP 已含 OurLittleDays.exe 與全部執行檔，**不用安裝 Python、不用下載原始碼、不用輸入指令、不用部署雲端網站**。支援 Windows 10/11 Intel / AMD 64 位元。

## 更新並啟動

1. 先在舊版按「記憶、事件與備份」→「備份整間公寓…」，將備份存到文件資料夾。關閉舊公寓視窗。
2. 登入自己的 GitHub 帳號，開啟私人儲存庫的下載頁：
   https://github.com/linda12392bb/our-little-days/blob/main/downloads/OurLittleDays-Windows-x64-Voice-0.3.1-preview.zip
3. 按檔案中間藍色 **View raw**，或右上方向下箭頭，下載 ZIP。這是下載，不需要預覽。不要按「Code → Download ZIP」，那是原始碼。
4. 到電腦「下載」資料夾，對 ZIP 按右鍵 →「全部解壓縮」。選新資料夾，例如「文件\OurLittleDays-Voice」。等待完成。
5. 打開解壓後的 OurLittleDays 資料夾，雙擊 OurLittleDays.exe。不要把 .exe 單獨搬出；同層的 _internal 與 speech-runtime 必須保留。
6. 原有聊天與記憶應自動出現。新版讀取同一個 Windows 帳號的本機永久資料。麥克風、AI 與擷取均先關閉，不會開機就付費。

目前沒有安裝精靈或數位簽章；若 Windows 顯示信任提示，請先核對檔案確實來自你自己的私人儲存庫。不要關閉防毒。如果程式被封鎖，保留提示內容供診斷。

使用者已確認 Phase 1 能在 Windows 11 擷取 Chrome。這次 Phase 2/3 尚待真正 Windows 測試，開發端封裝檢查不等於 Windows 實機或 AI 成本測試通過。

## 自動語音輸入

右側往下捲，先下載一次免費 base 多語模型，再按「開啟麥克風 · 自動偵測」。不用每句按鍵。先在 AI 關閉時測音量與文字預覽，確認後才啟用原文字 AI；原始音訊不保存或上傳。詳細步驟與實測：[VOICE_INPUT.md](VOICE_INPUT.md)。

## 準備 API

你已開通 OpenAI API。還需要在平台建立 API Key，且 API 帳號有可用計費額度：
https://platform.openai.com/api-keys

ChatGPT 訂閱與 API 計費分開。**請不要把 Key 貼到聊天室、GitHub 或截圖裡。**

1. 在公寓右側往下捲，找到「AI 與費用控制」，按「API 安全設定／月預算」。
2. 在密碼欄貼入自己的 API Key。金鑰由 Windows 帳號加密保存。
3. 模型先維持 **gpt-4.1-mini**；它支援圖片理解。程式沒有使用 GPT-6 LUNA。
4. 月預算預設 **NT$500**，可自行修改。最大輸出 2500 token，AI 最短間隔 120 秒可先維持。
5. 輸入／輸出價格是 USD／百萬 token，匯率是估算值。預填 $0.40 / $1.60、33，並非即時查價。請核對 https://openai.com/api/pricing/；若價格不同，在欄位修改。
6. 核對後勾選「已核對估算價格；同意 AI 使用完整人格、目前世界線聊天／記憶及選定視窗圖片」。
7. 按「保存設定」。這一步不會送出任何 API 請求。

如果保存金鑰報錯，請保留錯誤訊息；程式不會改存明文。移到其他 Windows 帳號、重裝 Windows 後要重新輸入 Key。

## 先做兩項單次成本測試

1. 開啟一個內容適合分析的 Chrome 視窗，避開金鑰與付款資料頁。
2. 公寓按「重新整理視窗」，選 Chrome，按「開始陪伴」。預覽正確即可；每 6 秒只是本機擷取。
3. 往下捲，按 **「單次畫面分析 · 測量費用」**。只送一次請求，成功後會顯示分析摘要、實際回報的輸入／輸出 token 及換算 NT$。
4. 在「訊息氣泡測試」的角色選單先選 **序**（也可選其他住戶）。按 **「單次所選角色回覆 · 測量費用」**。只送一次請求，角色回覆會保存到聊天室。
5. 記下兩次結果，核對模型、用量與「本月剩餘預算」。價格是本機估算；OpenAI 平台帳單可能稍晚更新。
6. 如果出現連線、金鑰、額度或格式錯誤，AI 會停止，不自動重試。可能已付費的請求會列為待確認預留額，避免低估。先處理錯誤再按單次測試。

兩項都成功並回報 usage 後，才能啟用長時間 AI。改模型／價格／匯率／輸出上限／Key 後需重做兩項測試。

## 文字回覆與自主陪伴

- 勾「啟用文字 AI 回覆」：送出訊息後，由完整十三聲道人格共同決定自然參與者。未勾選時訊息仍保存，但不呼叫 API。
- 再勾「啟用畫面事件自主陪伴」：可以完全不打字；畫面有明顯、相對穩定的新變化時才分析。一次請求可產生 0–4 人對話，標題箭頭顯示角色對誰接話。
- 沒有新畫面時可以一直安靜，120 秒到期本身不會觸發 API。初次自主觀察可能分析一次。大範圍動畫仍可能觸發，門檻之後依實測調整。
- 按「暫停所有 AI · 保留記憶」：停止付費工作，本機擷取仍可繼續。
- 按擷取「暫停」或「停止」：取消擷取與 AI，清除畫面預覽，聊天、記憶及已記錄用量保留。恢復後 AI 需重新手動勾選。
- 關閉程式：停止擷取與本機 API 工作。已送到平台的請求可能仍計費，不會因關閉而退款。重新開啟會恢復記錄，AI 預設關閉。

日英發言與敘事按段落附繁體中文翻譯。完整 source_text、人格與世界線設定保留，不因費用而刪減。聖護常駐主線是已正式交往，各 AU 分開。未確認的背景與人格核心不補寫。實際日文口吻、關西腔與互動自然度仍需回報調整。

## 剩餘額度與帳單

右側顯示本月剩餘預算、月預算、今日與本月估算、請求數、輸入／輸出 token、待確認／預留金額。

**這是程式內預算，並非 OpenAI 帳戶的信用餘額或實際帳單。** 達到估算預算，或無法預留下一次最大費用時停止呼叫。平台帳單：
https://platform.openai.com/settings/organization/billing/overview

所有本程式付費請求共用預算；本版沒有付費記憶摘要與自動重試。API 其他程式、稅金、匯差不在本機數字內。費用以你核對的價格換算，預算不是供應商端硬上限。

## 聊天、事件、備份與還原

資料位置：檔案總管網址列貼入 `%LOCALAPPDATA%\OurLittleDays`，按 Enter。也可雙擊程式資料夾內「開啟資料資料夾.cmd」。

- apartment.sqlite3：十三人格、關係、聊天、重要事件及長期記憶。
- api-usage.sqlite3：請求用量、費用與 AI 設定；還原聊天不清空用量。
- openai-key.dpapi：本機加密 Key；不要分享，不需提交 GitHub。

「記憶、事件與備份」→「備份整間公寓…」／「還原備份…」處理角色與聊天；還原需確認，並先備份當前資料。AI 觀察事件會標示未經使用者確認，不自動改戀愛關係；長期記憶可手動保存。

另到「API 安全設定／月預算」→「另行備份 API 用量紀錄…」。更新／重裝前，兩份備份都保留在其他安全位置。

還原時先還原公寓備份，再用設定內「合併還原 API 用量備份…」。用量採合併，不刪除現有新請求，避免還原舊備份後重新花完 NT$500。新 Windows 帳號需重新輸入 Key。不要手動刪除資料檔來重置預算或關係。

首次更新只把你已確認的序「調戲、♡」加到既有語氣／行為，先備份舊資料。其他角色人格與原文不會被種子覆寫。
